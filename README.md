# LED-экран: набор скриптов обслуживания

Набор BAT-скриптов для Windows и shell-скриптов для Android, предназначенных для
автоматизированного обслуживания LED-экранов (signage-планшеты с root-доступом):
установка фоновых сервисов, мониторинг сети, очистка кэша, отключение сетевого ADB
и снятие диагностических логов.

## Возможности

- **Установка одним запуском** — загрузка демонов на устройство, регистрация init-сервиса,
  перезагрузка и проверка результата (`install.bat` / `deploy.bat`).
- **Сетевой watchdog** — пингует `8.8.8.8`, при серии сбоев перезагружает устройство
  (с ограничением числа перезагрузок подряд) и ведёт лог с ротацией (`network_watchdog.sh`).
- **Плановая очистка кэша** — безопасная чистка каталогов `cache`/`code_cache` приложений
  и временных файлов 10-го и 20-го числа каждого месяца (цикл проверки — раз в час);
  кэш видеороликов офлайн-плеера (`files/content_cache`) **не удаляется** (`cache_cleaner.sh`).
- **Автозапуск после загрузки** — init-сервис запускает watchdog и cleaner через 90 секунд
  после `sys.boot_completed=1` (`led_monitor.rc` + `led_startup.sh`).
- **Защита устройства** — проверка целостности установки и **отключение сетевого ADB**;
  после перезагрузки `led_startup.sh` отключает ADB по TCP автоматически (`harden.bat`).
- **Диагностика** — статус процессов и последние логи (`check.bat`) и мощный инструмент
  сбора логов с кольцевыми буферами logcat и детектором инцидентов (`Снятие логов.bat`).

## Требования

- Windows 10/11 с установленным **ADB** (Android Platform Tools) в `PATH`.
- Устройство (LED-экран) с **root-доступом** (`adb root`) и возможностью монтирования `/vendor` в rw.
- Подключение по **USB** или по **сети** (IP:порт, по умолчанию `5555`).
- Все BAT-скрипты обращаются к `_adb_target.bat` — вспомогательному файлу выбора цели
  подключения (устройство USB/Wi-Fi). Убедитесь, что он присутствует рядом со скриптами.

## Структура репозитория

| Файл | Описание |
|---|---|
| `install.bat` | Установка скриптов на устройство: root, remount `/vendor`, push файлов, конвертация CRLF→LF, перезагрузки, проверка |
| `deploy.bat` | Универсальная установка: последовательно `install.bat` → `check.bat` → `harden.bat` |
| `check.bat` | Статус устройства: PID-файлы, живость процессов, логи watchdog/cleaner, счётчик ребута, статус сервиса, сетевой ADB, SELinux |
| `harden.bat` | Защита: проверка компонентов, отключение сетевого ADB, перезапуск `adbd`, контрольная проверка watchdog |
| `enable_network_adb.bat` | Включение сетевого ADB (порт по умолчанию 5555) для удалённого обслуживания |
| `uninstall.bat` | Полное удаление: остановка сервиса и процессов, удаление файлов; опция `--reset-adb` возвращает настройки ADB |
| `Снятие логов.bat` | Интерактивный сбор логов: кольцевые logcat (main/system/crash/events/kernel), детектор инцидентов, дампы logcat, dmesg, pstore, tombstones |
| `network_watchdog.sh` | Демон на устройстве: пинг-мониторинг сети, автоперезагрузка при обрыве (лимиты: 5 ошибок, 3 ребута), лог с ротацией |
| `cache_cleaner.sh` | Демон на устройстве: безопасная очистка кэшей приложений и временных файлов 10-го и 20-го числа месяца |
| `led_startup.sh` | Стартовый скрипт init-сервиса: отключение ADB по TCP после перезагрузки, запуск watchdog и cleaner |
| `led_monitor.rc` | Android init-сервис: запуск `led_startup.sh` по `sys.boot_completed=1` (user root) |
| `desktop.ini` | Служебный файл настроек папки Windows (не влияет на работу скриптов) |

## Быстрый старт

### 1. Установка на устройство (USB)

1. Включите отладку по USB на устройстве и подключите его кабелем.
2. Запустите `install.bat` (или `deploy.bat` для полной цепочки «установка + проверка + защита»).
3. Следуйте подсказкам: скрипт запросит перезагрузку, при Wi-Fi-подключении — новый IP-адрес.

### 2. Установка по сети

1. Подключитесь по USB и выполните `enable_network_adb.bat`.
2. Далее используйте скрипты с адресом устройства, например: `install.bat 192.168.1.50:5555`.

### 3. Проверка и защита

```bat
check.bat            REM статус всех компонентов и последние логи
harden.bat           REM проверка установки и отключение сетевого ADB
```

> После `harden.bat` сетевой ADB отключается. Для повторного удалённого доступа
> снова запустите `enable_network_adb.bat` (потребуется USB или текущее сетевое соединение).

### 4. Удаление

```bat
uninstall.bat                REM удалить сервисы и файлы
uninstall.bat --reset-adb    REM то же + вернуть настройки ADB в исходное состояние
```

### 5. Сбор логов при инцидентах

Запустите `Снятие логов.bat`, выберите тип подключения (USB / сеть) и режим:

- запуск кольцевых буферов logcat + монитор триггеров (ANR, Fatal signal, tombstone,
  watchdog, проблемы Wi-Fi/SD и т.п.) с сохранением фрагментов в `<папка>/incidents`;
- остановка и выгрузка колец в `<папка>/device_ring`;
- дампы `logcat -d`, `dmesg`, pstore, последние tombstones, тепловые данные.

## Расположение файлов на устройстве

| Путь | Назначение |
|---|---|
| `/vendor/etc/init/led_monitor.rc` | init-сервис автозапуска |
| `/vendor/etc/init/led_startup.sh` | стартовый скрипт (режим rw) |
| `/data/local/tmp/scripts/network_watchdog.sh` | демон мониторинга сети |
| `/data/local/tmp/scripts/cache_cleaner.sh` | демон очистки кэша |
| `/data/local/tmp/scripts/*.log`, `*.pid`, `reboot_counter.txt`, `last_clean_day.txt` | логи, PID-файлы и счётчики |
